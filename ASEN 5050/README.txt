This is the folder for ASEN 5050 Spaceflight Dynamics. This course focused on the 2 Body Problem, 
2 Body perturbations (J2, Solar Radiation Pressure, etc) and the N Body Problem. The course had biweekly
homework, with Analytical Assignments focused on derivations, proofs, and analysis of orbit properties. 
It also had Computational homework, focused on studying numerical methods for orbit determination, perturbation 
analysis and solving orbits that can't be solved analytically. 

Each homework has its own folder, labeled accordingly. All of the computational homework assignments were 
focused on developing a software package that could do all of the operations and analysis for the problems
on the homework. This has its own folder and has its own README and a tutorial Notebook. This is used in
all of the other assignments. Some Analytic homework assignments did not require any coding and have no folder.
